### Decks 2.11.0 — the deck directory

- Decks from the directory at decksmd.app/decks open in Obsidian from their page, or install from a downloaded .dpkg file. They sit in their own Deck directory section of the deck list and are reviewed like any other deck.
- A package can hold several decks. Its folder reviews each deck within that deck's own daily limits, and installing an update keeps your progress.
- Package decks study with the package's own profile. You can change its daily limits, review order, learning steps, retention, FSRS profile and voice; Reset returns them to the package's settings. A package profile cannot be deleted or mapped to a tag.
- An exam on a package uses the package's exam settings and draws its questions only from the package's exam decks.
- Export a note or a folder of decks as a Decks package (.dpkg), with a publisher name and handle, the decks in your order, exam decks with their questions, and the decks' study profiles.
- A package description can use Markdown: headings, lists, bold and links.
