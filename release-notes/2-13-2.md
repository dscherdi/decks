### Decks 2.13.2 — the database keeps working while Obsidian stays open

- Fixed: with Obsidian left open while other devices synced the vault, Decks could stop working after a few syncs. Decks, the review and the statistics then failed until Obsidian was restarted. The bundled database engine is updated to a version without this fault, and syncing no longer relies on the part that had it.
- After a sync that fails, Decks no longer reads and retries the same file every 2 seconds. It tries again once the file changes.
- With debug logging on, the log is appended to instead of being read and rewritten for every line, which took a lot of memory once the log was large. It moves to `debug.old.log` once it passes 1 MB.
