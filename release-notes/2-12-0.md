### Decks 2.12.0 — exam exercises

- Several questions about one text: under a question heading, write the text, then each question as a sub-heading (`###`). Under a sub-heading, a checklist is multiple choice, `==highlights==` are blanks to fill, and other text is the typed answer.
- For short exercises, write each question as a line of text above its own checklist under one heading.
- A comment below a question explains that question in the results.
- An exam shows an exercise on one screen, with its text beside the questions in a wide window. Each question is scored on its own.
- Exercises stay whole and in their written order when an exam draws or shuffles questions.
- A passage callout style for reading texts.
- The demo exam note now ends with two example exercises. An existing demo note is kept as it is; delete it and run "Create demo exam deck" to get the new one.
- Directory packages that contain exercises need this version to install.
