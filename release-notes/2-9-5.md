### Decks 2.9.5 — the AI prompt box no longer blanks when you hover it

The prompt box in **AI generate flashcards** went blank whenever the pointer was over it, and filled back in the moment you moved the mouse away.

Nothing was ever lost. The text was in the box the whole time and generating used it normally, even while the box looked empty.

#### **What was wrong**

The prompt box draws its text on two layers. One renders the text — that is the layer that turns an `@note` mention into a chip — and the input you actually type into sits on top of it, contributing only the caret.

Hovering made the input paint its own background, which is opaque, over the layer underneath. The text had not gone anywhere; the thing drawing it was covered up.

The red dotted spellcheck underline stayed visible the whole time, which is why the box looked oddly empty rather than simply blank: the spellchecker draws in its own colour, so it still showed through where the text could not.

#### **Also fixed**

Clicking into the box drew a focus ring *inside* the composer's own border, so the box appeared to have two outlines while you typed. Same cause, gone with it.

#### **Unrelated, but worth knowing**

Between mid-August and 15 September, Decks Pro generation on the **Flash** tier failed with *"the service is temporarily unavailable"*. The cause was server-side and has already been fixed for everyone — it never needed a plugin update, and this release changes nothing about it. **Thinking** was unaffected throughout.
