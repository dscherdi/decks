### Decks 2.8.7 — mobile deck-list fixes

This release fixes two visual issues in the deck list on mobile.

#### **The expand arrow no longer looks like a button**

A row's expand/collapse arrow is a plain caret again on mobile. It no longer stretches into a wide tap target or shows a filled background when pressed, and tapping an already-open row no longer makes the arrow flip back — it just rotates.

#### **The column header matches the row height**

The Deck / New / Due header row is now the same height as the deck rows on mobile, matching the desktop layout.
