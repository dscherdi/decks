### Decks 2.8.6 — unified Profiles modal and in-app documentation links

This release merges profile settings and deck assignment into one modal, adds documentation links throughout the app, and makes the deck list more compact on mobile.

#### **Profiles and deck assignment in one modal**

The **Profiles** modal now has two tabs. **Settings** edits the selected profile — daily limits, again intervals, card parsing, exams, review order, FSRS, and read-aloud. **Assignments** maps tags to that profile: pick a tag and **Apply**, and every deck under it inherits the settings. Each assigned tag shows how many decks and cards it covers and can be removed (its decks fall back to the inherited profile), and an **Effective settings** summary recaps what those decks actually get.

A shared picker at the top switches the active profile and offers **New**, **Duplicate**, and **Delete**. This replaces the separate deck-configuration dialog, so the deck-list header now has a single button that opens the Profiles modal. A deck's **Configure profile** menu option opens the same modal on the **Assignments** tab.

#### **Documentation links throughout the app**

The deck panel, review, exams, the flashcard manager, filter builder, profiles, AI generator, statistics, the image-occlusion studio, and settings each have an **(i)** button that opens the matching documentation page in your browser.

#### **A more compact deck list on mobile**

The deck-list header and rows are now as compact on mobile as on desktop. A leftover minimum row height that only applied on phones and touch devices has been removed.
