### Decks 2.10.1 — exam cloze fixes

- Exams no longer show the answer of a cloze written in a card's front, such as a one-column table row. The sentence is shown with a blank to type the answer into.
- In exams, a `==highlight==` inside inline code is no longer taken for the blank.
- Blanks in exam answer lists show as text instead of turning into links or lines.
- The plugin's source now installs with npm on its own, for automated reviews of the code.
